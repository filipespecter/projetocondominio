CORREÇÃO ADICIONAL — ERROS OPERACIONAIS + TEMA POR CONDOMÍNIO
==============================================================

Durante a validação manual no Windows foram observados HTTP 500 simultâneos em vários módulos operacionais (apartamentos, moradores, porteiros, documentos, ativos, fornecedores, contratos etc.). Todos esses módulos compartilham o mesmo subscriptionAccessMiddleware. O middleware foi simplificado para consultar apenas os campos estáveis necessários para autorização (id/status do condomínio e da assinatura), evitando que colunas auxiliares de cobrança ou eventual drift histórico do banco derrubem toda a área operacional. Em caso de drift real de tabela/coluna, agora é devolvido diagnóstico DATABASE_SCHEMA_OUT_OF_SYNC em vez de erro 500 genérico.

Tema visual por condomínio:

- O sistema gera automaticamente tons claros/escuros/bordas a partir da cor principal.
- Síndico/gestor, morador e porteiro recebem a mesma identidade visual do condomínio.
- A paleta roxa fixa das telas operacionais foi convertida para variáveis de tema.
- A Central Star e páginas fora do contexto do condomínio continuam com a paleta padrão da marca.
- Alterar o seletor de cor aplica uma prévia imediatamente; salvar persiste no JSON settings do condomínio.

CORREÇÃO DE VALIDAÇÃO — EXPRESS 5 / req.query (2026-09-12)
==========================================================
A validação manual no Windows revelou a causa real dos HTTP 500 restantes: alguns validadores tentavam executar `req.query = result.data`. No Express 5, `req.query` é exposto por getter e não pode ser sobrescrito por atribuição simples, gerando `TypeError: Cannot set property query of #<IncomingMessage> which has only a getter`.

Correção aplicada:
- todos os validadores operacionais que normalizam filtros de query foram ajustados para definir a query validada de forma compatível com Express 5;
- corrigidos Documentos, Auditoria, Apartamentos, Visitantes, Prestadores, Moradores, Acessos de Prestadores, Avisos, Encomendas, Reservas, Ocorrências, Porteiros, Áreas Comuns e Notificações;
- nenhuma regra de negócio, tenant, QR ou autenticação foi removida;
- tema OPT-IN por condomínio permanece preservado.

Regressão adicionada:
- middleware de query validado contra objeto com getter somente leitura, reproduzindo o comportamento do Express 5;
- varredura garante que nenhum dos validadores operacionais volte a usar atribuição direta em `req.query`.
